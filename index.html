L'auteur reste au centre.

L'outil accompagne la création : recherche, structure, réécriture, documentation, images, préparation à la publication. La décision littéraire demeure humaine.

Atelier

Créer avec l'IA, sans céder son écriture.

L'atelier est pensé comme un compagnon de travail : faire émerger une piste, comparer des formulations, construire une chronologie, documenter un personnage, préparer une image ou tester une structure.

Pas de texte imposé. Pas de « bouton magique pour devenir écrivain ». L'outil propose ; l'auteur choisit.

Mise en ligne

Les trois dernières étapes

Le prototype est prêt à quitter l’aperçu. Nous allons maintenant le publier sur un hébergement HTTPS, vérifier Supabase depuis cette adresse réelle, puis activer l’authentification.

01 · Hébergement

Publier le site

Mettre le fichier HTML autonome sur un hébergement web HTTPS et obtenir sa première adresse publique.

02 · Supabase

Tester le serveur

Depuis l’adresse publique, vérifier que l’URL Supabase et la clé publishable communiquent correctement.

03 · Authentification

Ouvrir les comptes

Raccorder ensuite les comptes auteurs à Supabase Auth, sans exposer de clé secrète dans le navigateur.

Configuration

Connexion au serveur

Configuration Supabase conservée pour le test depuis le site hébergé.
